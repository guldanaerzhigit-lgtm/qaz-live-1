# QAZ LIVE

QAZ LIVE — адаптивная социальная платформа на React + Vite: лента публикаций, профили, XP и достижения, персональные виртуальные миры, сообщения и QAZ LAB.

## Cloudflare Pages

- Framework preset: **Vite**
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`

После добавления коммитов Cloudflare Pages автоматически пересоберёт сайт, если репозиторий подключён к Pages.

## Запуск локально

Требуется Node.js 18 или новее:

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Установка на телефон

Приложение содержит PWA manifest, фирменную SVG-иконку и service worker для кэширования оболочки. После production-деплоя открой сайт в Chrome на Android и выбери **«Установить приложение»** или **«Добавить на главный экран»**. Онлайн-функции по-прежнему требуют подключения к интернету.

## Возможности проекта

- Firebase Authentication и Firestore для аккаунтов и социальных данных.
- Лента, публикации, реакции и комментарии.
- Подписки и уведомления.
- Личные чаты на базе Firestore.
- Профили, XP, уровни и достижения.
- Персональный виртуальный мир с темами и декором.
- QAZ LAB с заявками на доступ и административной модерацией.
- Жалобы и инструменты администрирования, защищённые Firestore Rules.

## Важные ограничения перед публичным запуском

Некоторые настройки мира, достижения, прогресс и отдельные мини-функции пока хранятся в `localStorage`. Они не синхронизируются между устройствами. Необходимо переносить пользовательские данные в Firestore поэтапно и проверять правила доступа для каждой коллекции.

PWA-кэш хранит только оболочку приложения; он не кэширует Firebase/API-запросы и не превращает онлайн-функции в автономные.

Перед запуском для широкой аудитории:
1. Проверить регистрацию, восстановление доступа и вход на реальном устройстве.
2. Проверить Firestore Rules на разрешённые и запрещённые сценарии.
3. Перенести профиль и настройки виртуального мира в Firestore.
4. Проверить отправку/получение сообщений, уведомления и загрузку изображений.
5. Добавить отчёт об ошибках, политику конфиденциальности и правила сообщества.
6. Не хранить секретные ключи или service-account JSON в клиентском коде или GitHub.

Firebase web config в клиентском приложении не является серверным секретом; безопасность данных обеспечивается корректными Firebase Security Rules и настройками проекта.
